# B站医学科普视频参考文献

本仓库按 B站视频项目的目录层级，公开 GuiMing机制局医学科普视频所使用的参考文献、官方来源、许可状态和具体用途。

当前目录格式：

```text
栏目/
└── 子系列/
    └── 期号/
        ├── README.md
        ├── references.csv
        └── references/
            ├── open/       # 明确允许再分发的全文
            └── linked/     # 未确认开放再分发许可，仅提供引文和官方链接
```

## 收录原则

1. 每一期独立建立文件夹，不把多期文献混在同一目录。
2. 每条资料必须记录题名、作者或发布机构、年份、文献类型、DOI或标准号、原始来源、许可、成片用途和校验值。
3. 明确为 CC BY、CC0 或 Public Domain 的全文可以保存到 `references/open/`，并在相邻索引中完整署名。
4. 没有明确开放再分发许可的标准、指南、教材或期刊全文不上传；改存到 `references/linked/`，提供完整引文和官方入口。
5. “可在线阅读”不等于“允许在 GitHub 再分发”。许可不清时一律采用链接模式。
6. 仓库不保存成片、口播音频、封面、未公开制作文件、账号信息或付费数据库内容。
