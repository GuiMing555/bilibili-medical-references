# 每期参考文献归档流程

## 1. 建立当期目录

```bash
python scripts/new_episode.py \
  --series 检验说明书 \
  --topic 血常规 \
  --episode 03 \
  --title "本期标题"
```

目录名称跟随本地 B站视频文件夹：`栏目/子系列/两位期号`。

## 2. 填写来源台账

在当期 `references.csv` 中逐项填写：

- 文献题名；
- 作者或发布机构；
- 年份和文献类型；
- DOI、指南号或标准号；
- 原始来源 URL；
- 明确的许可名称；
- `file` 或 `link-only`；
- 成片中的具体用途。

## 3. 决定是否上传全文

- CC BY、CC0、Public Domain：全文放入 `references/open/`，填写相对路径和 SHA-256。
- 许可不清、仅可阅读、需要登录或版权所有：全文不上传，在 `references/linked/` 建立同名 Markdown，记录完整引文、官方入口和未上传原因。
- 不以转载站、网盘或搜索结果页替代原始来源。

## 4. 校验

```bash
python scripts/validate_references.py
```

校验会检查字段、来源链接、开放许可、文件存在性和 SHA-256。GitHub Actions 会在每次推送和拉取请求时再次执行。

## 5. 写入B站简介

每期B站描述必须在医学内容介绍之后、科普声明之前加入：

```text
引用文献与来源：
https://github.com/GuiMing555/bilibili-medical-references
```

不要使用Markdown隐藏链接，直接保留完整地址，便于B站页面识别和观众复制。

## 6. 提交

每期只提交新增期号目录及必要的总索引更新。不要提交成片、口播、封面、账号配置、Cookie、API密钥或付费数据库全文。
